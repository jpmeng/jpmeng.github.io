Concise Modern C++: A Bridge from Python, MATLAB, and Mathematica

C++ is a powerful programming language that supports a wide range of scientific computing applications and provides the computational backbone for the AI revolution. Modern features have been gradually added to C++, simplifying the development of scientific applications. However, these features often involve complex concepts and techniques—particularly template programming—which results in a steep learning curve.

This article connects and compares key features of modern C++ with other languages used in scientific computing, including Mathematica, Python, and MATLAB. We will find that many modern C++ features are fundamentally the same as those in other research-oriented languages, differing only in their syntax and implementation details.

Container

A container is a data structure or object that can hold and organise other data structures and objects. Mapping this concept to scientific computing, the most commonly used one is array that holds a series of numbers, i.e., the array of Matlab and numpy, and the list of Mathematica and Python.

In C++, the most commonly used container for implementing arrays is std::vector, a part of the C++ Standard Library. It is a dynamic array that can grow and shrink in size. In the following example, we will see how to define and use std::vector in C++.

// to import the iostream library for input and output
#include <iostream>
// to import the vector library
#include <vector>

// Make std::cout able to print our a vector
template <typename T>
std::ostream& operator<<(std::ostream& os, const std::vector<T>& v) {
    os << "[ ";
    for (const auto& x : v) os << x << " ";
    os << "]";
    return os;
}
int main() {
    //define a double array
    std::vector <double> realArray{0.1,1,2};
    //define a integer array
    std::vector <int> intArray{1,2,3};
    //define a float array of size 10 with an initial value 1
    std::vector <float> floatArray(10,1);
    std::cout << realArray << "\n";
    std::cout << intArray << "\n";
    std::cout << floatArray << "\n";
    for (int i=0;i<10;++i){
        floatArray[i]=(i+1)*(i+1);
    }
    std::cout << "Now we modify the floatArray:" << "\n";
    std::cout << floatArray << "\n";

    return 0;
}

To test the code, we can copy and paste it into an online C++ compiler, e.g., https://www.programiz.com/cpp-programming/online-compiler/.

To implement the same functionality in Mathematica, we can use lists to define arrays and modify them as follows:

(* define a double array *)
realArray = {0.1, 1, 2};

(* define an integer array *)
intArray = {1, 2, 3};

(* define a float array of size 10 with initial value 1 *)
floatArray = ConstantArray[1., 10];

Print[realArray];
Print[intArray];
Print[floatArray];

(* modify floatArray: floatArray[i] = (i+1)^2 *)
For[i = 1, i <= 10, i++,
    floatArray[[i]] = i^2;
];

Print["Now we modify the floatArray:"];
Print[floatArray];

Similarly in Matlab, we can define and modify arrays as follows:

% define a double array
realArray = [0.1, 1, 2];

% define an integer array
intArray = [1, 2, 3];

% define a float array of size 10 with initial value 1
floatArray = ones(1, 10, 'single');

disp(realArray);
disp(intArray);
disp(floatArray);

% modify floatArray: floatArray[i] = (i+1)^2
for i = 1:10
    floatArray(i) = i^2;
end

disp("Now we modify the floatArray:");
disp(floatArray);

In Python, we can use lists to define and modify arrays as follows:

# define a double array
realArray = [0.1, 1, 2]

# define an integer array
intArray = [1, 2, 3]

# define a float array of size 10 with initial value 1
floatArray = [1.0] * 10

print(realArray)
print(intArray)
print(floatArray)

# modify floatArray: floatArray[i] = (i+1)*(i+1)
for i in range(10):
    floatArray[i] = (i + 1) * (i + 1)

print("Now we modify the floatArray:")
print(floatArray)

The Python code can also be tested in an online without installing Python, e.g., https://www.programiz.com/python-programming/online-compiler/.

Comparing the four languages, we can see that the way to define and modify arrays is quite similar, with some differences in syntax. Specifically, as a compiled language, C++ requires more boilerplate codes, particularly for declaring the type of the array element, e.g., int in std::vector<int> which declares the vector element type as integer, which is not necessary in the other languages. However, in this way, more control over memory and performance can be achieved in C++, which is crucial for scientific computing applications.

Rich containers are available in C++ Standard Library, e.g., std::list, std::deque, std::set, std::map, etc. These containers provide different functionalities and performance characteristics, and they can be used in various scientific computing applications depending on the requirements of the problem at hand, though might be less common.

Algorithm

In term of modern C++, the algorithm defines operations for containers. This is different from the numerical algorithms in scientific computing that define a series of mathematical operations to solve a scientific problem. However, the algorithms in C++ can be used to implement the numerical algorithms in scientific computing, which may involve multiple algorithms and containers.

For example, the std::transform algorithm can be used to apply a function to each element in a container, which is a common operation in scientific computing when we want to apply a mathematical operation to each element in an array.

The code below is using std::transform to square each element in a vector (array). We will also see how to implement the same functionality in Mathematica and Python.

#include <iostream>
#include <vector>
// Required for std::transform
#include <algorithm>
// Define a named function to square a integer
int square (int x) { return x * x; };
#include <string>
int main() {
    //prepare the array (container)
    std::vector<int> data = {1, 2, 3, 4, 5};
    //AApply the square function to each element in the vector
    std::transform(data.begin(),data.end(),data.begin(),square);
    // Print the results
    std::cout << "Squared: ";
    for (int n : data) {
        std::cout << n << " ";
        // Output: 1 4 9 16 25
    }
    return 0;
}
(* Define the square function*)
square[x_] := x * x

(* Prepare the data *)
data = {1, 2, 3, 4, 5};

(* Using Map to apply the square function to each element in the data *)
squaredData = Map[square, data];

Print["Squared: ", Row[squaredData, " "]]
(* Output: Squared: 1 4 9 16 25 *)
# define the square function
def square(x):
    return x * x

# Prepare the data
data = [1, 2, 3, 4, 5]

# Apply the square function to each element in the data using map
data = list(map(square, data))

print(f"Squared: {' '.join(map(str, data))}")
# Output: Squared: 1 4 9 16 25

As we can see again, the concept of applying a function to each element in a container is common across C++, Mathematica, and Python, though the syntax and specific functions used may differ.

In essence, std::transform, similar to its variants in other languages, is a higher-order function that a replaces a manual for loop, which often results in more concise and efficient code. Because it expresses the intent of the operation rather than just the mechanics, the compiler can more easily apply optimizations—like vectorization and parallelism—that a manual loop might obscure.

Lambda Expressions

In the above examples, we defined a few named functions for squaring the numbers in various languages. However, in many cases, we only need to use the required operations once and defining a proper function becomes cumbersome. To help with this, we can use lambda expressions, which are anonymous functions that can be defined and used inline. Lambda expressions are particularly useful when we want to pass a simple function as an argument to an algorithm like std::transform. With lambda expressions, the C++ code for squaring each element in a vector can be written more concisely as follows:

#include <iostream>
#include <vector>
// Required for std::transform
#include <algorithm>
int main() {
    std::vector<int> data = {1, 2, 3, 4, 5};
    // Define a lambda expression to square a number
    auto square = [](auto x) { return x * x; };
    // Use std::transform to apply the lambda to data
    std::transform(data.begin(),data.end(),data.begin(),square);
    // Print the results
    std::cout << "Squared: ";
    for (int n : data) {
        std::cout << n << " ";
        // Output: 1 4 9 16 25
    }
    return 0;
}

or even more concisely without defining a named lambda variable:

#include <iostream>
#include <vector>
// Required for std::transform
#include <algorithm>
int main() {
    std::vector<int> data = {1, 2, 3, 4, 5};

    // Use std::transform to apply a lambda to data
    std::transform(data.begin(),data.end(),data.begin(),[](auto x) { return x * x; });
    // Print the results
    std::cout << "Squared: ";
    for (int n : data) {
        std::cout << n << " ";
        // Output: 1 4 9 16 25
    }
    return 0;
}

Similarly we can perform the same operation in Mathematica, Python, and MATLAB as follows:

(* Mathematica *)
data = {1, 2, 3, 4, 5};
square = #*# &;
Map[square, data]
(* Output: {1, 4, 9, 16, 25} *)
Map[#*# &, data]
(* Output: {1, 4, 9, 16, 25} *)
# Python
data = [1, 2, 3, 4, 5]
square = lambda x: x * x
list(map(square, data))
# Output: [1, 4, 9, 16, 25]
list(map(lambda x: x * x, data))
# Output: [1, 4, 9, 16, 25]
% MATLAB
data = [1, 2, 3, 4, 5];
square = @(x) x.^2; % The Lambda (Function Handle)
% arrayfun is the MATLAB "Map"
results = arrayfun(square, data)
% Output: [1 4 9 16 25]
results = arrayfun(@(x) x.^2, data);
% Output: [1 4 9 16 25]

As we can see, apart from the different syntax, the concept of lambda expressions is quite similar across C++, Mathematica, Python, and MATLAB. A small, inline functions can be defined and passed to higher-order functions like std::transform, Map, map, and arrayfun to perform operations on data.

Thrust example

In this example, we provide a code using the Thrust library to square an integer array. The code uses theThrust version of the std::vector (container), transform function, and a lambda expression for the purpose. In most of the case, we simply replace the std:: with thrust:: to use the Thrust library. With some minor modifications, the same code can be executed on both CPU and GPU, which is not only concise but also often more efficient.

// square.cu
#include <thrust/host_vector.h>
#include <thrust/device_vector.h>
#include <thrust/sequence.h>
#include <thrust/transform.h>
#include <thrust/execution_policy.h>
#include <iostream>

int main() {
    const int N = 10;

    thrust::host_vector<int> h_input(N);
    thrust::sequence(h_input.begin(), h_input.end(), 1); // 1, 2, ..., 10
    thrust::host_vector<int> h_output(N);

    // Define the Square Lambda
    // __host__ __device__ allows this code to run on both CPU and GPU
    auto square = [] __host__ __device__ (int x) {
        return x * x;
    };

    // Execute on Host
    thrust::transform(thrust::host, h_input.begin(), h_input.end(), h_output.begin(), square);

    // Setup Device Data (GPU)
    // Assignment handles the memory copy (cudaMemcpy) automatically
    thrust::device_vector<int> d_input = h_input;
    thrust::device_vector<int> d_output(N);

    // Execute on Device
    thrust::transform(thrust::device, d_input.begin(), d_input.end(), d_output.begin(), square);

    // Validation
    thrust::host_vector<int> gpu_results = d_output; // Copy back to CPU for printing

    std::cout << std::left << std::setw(10) << "Input"
              << std::setw(12) << "Host"
              << std::setw(12) << "Device" << "\n";
    std::cout << std::string(34, '-') << "\n";

    for(int i = 0; i < N; i++) {
        std::cout << std::setw(10) << h_input[i]
                  << std::setw(12) << h_output[i]
                  << std::setw(12) << gpu_results[i] << "\n";
    }

    return 0;
}

To test this code, we need to install the CUDA toolkit, see https://developer.nvidia.com/cuda-downloads and compile the code with nvcc (the NVIDIA CUDA Compiler) as follows:

nvcc -o square square.cu -std=c++20 --extended-lambda

Summary

In this article, we have introduced some key features of modern C++ for scientific computing, including containers, algorithms, and lambda expressions. We have also compared these features with their counterparts in other languages commonly used in scientific computing, such as Mathematica, Python, and MATLAB.

While the syntax and specific implementations may differ, we can migrate our concept learned from other languages, like Python, MATLAB, and Mathematica, and use modern C++ to write concise but performant code for scientific computing applications.
